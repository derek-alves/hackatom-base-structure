# 0005 - MCP nos dois sentidos: servir as tools em /mcp e consumir servidores MCP

Status: aceita (2026-11-23).

## Contexto

No hackathon, o time pode precisar ligar o agente a sistemas que já falam MCP (servidores da empresa, do Google, de parceiros) e expor o que construiu para outros agentes (Claude Code, Antigravity, o agente de outro time). Os jurados do Google AI Agents Challenge destacaram o "MCP bidirecional": o agente consome ferramentas por MCP e publica o próprio raciocínio como servidor MCP, com controle de acesso.

O ADK 2.14 já traz o `McpToolset` (cliente por stdio, SSE ou Streamable HTTP). O SDK `mcp` vem pelo extra `google-adk[mcp]` e, na versão 2.x, chama o servidor de `MCPServer` (antigo `FastMCP`).

## Decisão

**Servir (`app/core/mcp/server.py`).**
- Toda tool de `AppModule.tools` também é publicada como tool MCP em `/mcp` (Streamable HTTP, sem estado, resposta JSON). Nome e docstring são os mesmos que o agente vê. Criar uma tool num módulo já a publica.
- As rotas entram direto no router do FastAPI. Montar uma sub-app serviria `/mcp/` e redirecionaria `/mcp`, e clientes MCP não seguem esse redirect num POST.
- O `StreamableHTTPSessionManager` roda no `lifespan` do app.
- Proteção contra DNS rebinding: só `Host` de localhost, mais `MCP_SERVER_ALLOWED_HOSTS` (ex.: `'["192.168.0.10:*"]'` para colegas na rede).
- `MCP_SERVER_TOKEN` opcional exige `Authorization: Bearer <token>` (comparação em tempo constante). `MCP_SERVER_ENABLED=false` desliga.

**Consumir (`app/core/mcp/client.py`).**
- `MCP_SERVERS` é uma lista JSON. Cada item tem `name` (prefixo das tools: `<name>_<tool>`), `url` + `headers` (HTTP) ou `command` + `args` + `env` (stdio), `tools` (filtro opcional) e `timeout`.
- Cada servidor vira um `McpToolset` passado ao `ui_agent` junto com as tools dos módulos. A conexão abre no primeiro uso e fecha no shutdown.
- `build_app`/`build_ui_agent` passam a aceitar `ToolUnion` do ADK (função, `BaseTool` ou `BaseToolset`).

**Exemplo (`backend/mcp_servers/quotes/`).**
- Servidor MCP próprio, fora de `app/`, que roda como processo separado: `python -m mcp_servers.quotes` (stdio) ou `--http 8100`. Cotações fictícias de câmbio e ativos. Modelo para copiar ao criar um servidor novo.
- O Containerfile copia `mcp_servers/` para o servidor rodar por stdio dentro do container.

## Consequências

- As tools de escrita (`create_record`, `update_record_status`) ficam acessíveis por MCP a quem alcança a porta, como já acontece com as rotas REST. Na rede do evento, use `MCP_SERVER_TOKEN` ou `MCP_SERVER_ENABLED=false`.
- Servidor de `MCP_SERVERS` fora do ar faz o turno do agente falhar quando o modelo tenta listar ou chamar as tools; o stream emite `error` e `done`. No modo demo `replay`, as tools rodam de verdade, então os servidores MCP precisam estar no ar.
- Resposta grande de tool MCP vai inteira para o contexto do modelo. Use `tools` para filtrar e prefira servidores com respostas enxutas.
